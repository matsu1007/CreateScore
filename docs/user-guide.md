# CreateScore ユーザーガイド

鼻歌やヴォカリーズを歌うだけで MIDI ファイルを作成できるアプリです。

---

## 基本的な使い方

```
① 録音する → ② 解析する → ③ ピアノロールで確認・編集する → ④ MIDI 出力する
```

---

## 各パネルの説明

### 録音パネル

マイクから音声を録音します。

| ボタン | 説明 |
|---|---|
| **Record** | 録音を開始します。最長 60 秒で自動停止します |
| **Stop** | 録音を手動で停止します |
| **Play Original** | 録音した音声をそのまま再生します（確認用） |
| **Clear** | 録音データを消去して最初からやり直します |
| **メトロノーム確認** | 現在の BPM で 8 拍分のメトロノーム音を鳴らします。テンポ感を確かめるのに使います |

**録音メトロノーム（チェックボックス）**  
録音中にメトロノームを鳴らします。テンポに合わせて歌いたいときに ON にしてください。

> **状態バッジ**（録音パネル右下）に現在の状態が表示されます。  
> `Empty` → `Recording` → `Recorded` → `Analyzing` → `Ready` の順に遷移します。

---

### 解析・設定パネル

録音した音声をピッチ解析して音符に変換するための設定です。

#### グリッド設定

| 項目 | 説明 |
|---|---|
| **BPM** | 曲のテンポ（拍/分）を設定します。範囲: 40〜240。**Analyze を実行する前に正しい値を設定してください** |
| **Division** | 最小音符の長さ（グリッド分割）を選びます |
| **Tap Tempo** | このボタンを手でリズムよく連打すると BPM を自動推定します。6 回以内の入力で計算されます |

**Division の選び方**

| 値 | 最小音符 | 用途 |
|---|---|---|
| 1/8 | 8 分音符 | ゆっくりめのメロディ、シンプルなリズム |
| 1/16 | 16 分音符 | 標準的なポップス・歌メロ |
| 1/32 | 32 分音符 | 細かい音符が多い速いメロディ |

#### ピッチ検出設定

| 項目 | 説明 |
|---|---|
| **Deadband（cents）** | 同じ音符とみなすピッチのぶれ幅（セント単位、100 セント = 1 半音）。値を大きくすると細かいゆらぎを無視します。ビブラートの強い歌声には大きめの値（50〜70）を推奨します |
| **Backend** | ピッチ検出エンジンを選びます（詳細は下記） |
| **Model** | CREPE バックエンド使用時のモデルサイズを選びます（tiny / full） |
| **confMin** | ピッチ検出の信頼度下限（0〜1）。この値より信頼度が低いフレームは「無音」扱いになります。ノイズが多い場合は値を上げてください |
| **batch** | CREPE バックエンド使用時の処理バッチサイズです。通常は変更不要です |

**Analyze ボタン**  
設定を確定して解析を実行します。進捗（0〜100%）が表示されます。完了すると「Ready」状態になります。

#### Backend（ピッチ検出エンジン）の比較

| Backend | 精度 | 速度 | 必要条件 |
|---|---|---|---|
| **CREPE (WebGPU)**（デフォルト） | 高い | やや遅い | GPU 対応ブラウザ（Chrome/Edge 推奨）+ モデルファイル |
| **CREPE (WASM)** | 高い | 遅い | モデルファイル |
| **YIN** | 標準 | 速い | なし |

> **CREPE を使うには** `public/model/` に `crepe_tiny.onnx`（または `crepe_full.onnx`）を手動で配置する必要があります。WebGPU が使えない場合は自動的に WASM へフォールバックします。

#### モデルサイズ（CREPE 使用時のみ）

| Model | 精度 | 速度 |
|---|---|---|
| **tiny** | やや低い | 速い |
| **full** | 高い | 遅い |

### ピッチカーブ

解析後に表示されます。時間軸（横）とピッチ（縦）の関係をグラフで示します。

- **点の色**：緑に近いほど検出信頼度が高く、赤に近いほど低いです
- 上段の数値：フレーム総数、有声フレーム数と割合、平均信頼度

ピッチが乱れている箇所は音符の精度が下がります。その場合は `Deadband` や `confMin` を調整して再解析してください。

---

### Piano Roll 編集

解析結果の音符を確認・編集します。ピアノロール上部のバーにはコードのルート音（例：C、G、Am）が小節ごとに表示されます。

#### ツールバーボタン

| ボタン | 説明 |
|---|---|
| **モバイル複数選択 ON/OFF** | ON にすると、タップ/クリックするたびに音符を追加選択・解除できます。マウスの Shift + クリックでも複数選択できます |
| **Undo** | 直前の編集操作を元に戻します。最大 5 回まで戻せます |
| **Redo** | Undo で戻した操作をやり直します |
| **-1semi / +1semi** | 全ての音符を 1 半音下げ/上げします（移調） |
| **-1oct / +1oct** | 全ての音符を 1 オクターブ下げ/上げします |
| **Split** | 1 つだけ選択した音符を、クリックした位置で 2 つに分割します |
| **Join** | 選択した複数の音符をつなげます。同じ音高かつ連続している音符のみ結合されます |
| **Delete** | 選択した音符を削除します |

#### ピアノロールの操作

| 操作 | 動作 |
|---|---|
| 音符をクリック | その音符を選択します |
| 空白をクリック | 選択を解除します |
| Shift + クリック | 複数の音符を追加選択します |
| 音符をドラッグ | 選択した音符を時間軸（左右）・音高（上下）方向に移動します |
| 空白をドラッグ | ピアノロール全体を左右にスクロールします |
| ホイールスクロール | 左右にスクロールします |

> **Split の使い方**: まず 1 つの音符をクリックして選択 → ピアノロール上でカーソルを分割したい位置に合わせてクリック（splitTick が更新される）→ Split ボタンを押す。

### LLM 補正

ローカル AI（Ollama + Gemma4 12B）を使って、音符のピッチやリズムを自動的に補正します。

> この機能を使うには、事前に [Ollama](https://ollama.com/) をインストールし、`gemma4:12b` モデルをダウンロードしておく必要があります。

#### 準備

```bash
# Ollama のインストール後、モデルをダウンロード
ollama pull gemma4:12b

# Ollama を起動（インストール後に自動起動している場合は不要）
ollama serve
```

#### 操作

| ボタン | 説明 |
|---|---|
| **Gemma4 で補正を実行** | AI による補正を開始します。まず Ollama への接続確認を行い、成功したら補正を実行します |
| **キャンセル** | 補正中に中断します |

**ステータス表示**

| 表示 | 意味 |
|---|---|
| `○ Ollama に接続中...` | Ollama が起動しているか確認しています |
| `◉ 補正中... Ns (M tokens)` | AI が応答を生成中です。N 秒経過、M トークン受信済み |
| `✓ N 音符を修正しました` | 補正完了。N 個の音符が変更されました |
| `✗ エラーメッセージ` | 接続失敗または補正エラー |

> - 補正後は **Undo** で元に戻せます
> - Gemma4 12B は大きなモデルのため、補正に数分かかる場合があります
> - 「port is already in use」エラーが出た場合は、Ollama はすでに起動しています。そのまま補正を再試行してください

---

### 出力パネル

音符の再生と MIDI ファイルの書き出しを行います。

| ボタン | 説明 |
|---|---|
| **ノート再生** | 現在のピアノロールの音符をブラウザで再生します（サイン波で発音） |
| **一時停止 / 再開** | 再生を一時停止・再開します |
| **停止** | 再生を停止します |
| **Export MIDI** | ピアノロールの音符を SMF（Standard MIDI File）形式で書き出します。ファイル名は `humming.mid` です |

## 推奨ワークフロー

### 1. テンポを決める

BPM 欄に曲のテンポを入力するか、Tap Tempo で推定します。「メトロノーム確認」ボタンで実際の速さを耳で確かめてください。

### 2. 録音する

「録音メトロノーム」を ON にしてメトロノームに合わせて鼻歌を録音します。録音後「Play Original」で音声を確認できます。

### 3. 解析する

設定を確認して「Analyze」ボタンを押します。初めて使う場合は YIN バックエンドで試してみてください。

### 4. ピアノロールを確認・編集する

音符がずれていたら以下の手順で修正します：

- **オクターブがずれている** → `-1oct` / `+1oct` で調整
- **半音ずれている** → `-1semi` / `+1semi` で調整
- **特定の音符だけおかしい** → クリックして選択 → ドラッグで移動
- **音符が分断されている** → 両方選択して Join
- **1 つの音符が長すぎる** → 選択して Split

### 5. LLM 補正（任意）

Ollama が利用可能な場合は「Gemma4 で補正を実行」で AI 補正を試してみてください。

### 6. MIDI を書き出す

「Export MIDI」で `.mid` ファイルをダウンロードします。DAW や楽譜ソフトに読み込んで活用してください。

## よくある問題

### 音符が全体的にオクターブずれている

解析後に `-1oct` または `+1oct` ボタンで一括調整できます。

### 音符が多すぎる・細切れになる

- `Deadband（cents）` の値を大きくする（例: 35 → 60）
- `confMin` の値を大きくする（例: 0.3 → 0.5）
- 再解析する

### 音符が少なすぎる・消えてしまう

- `confMin` の値を小さくする（例: 0.3 → 0.15）
- 録音環境のノイズを減らして再録音する

### LLM 補正が「接続できません」と表示される

Ollama が起動していない可能性があります。ターミナルで以下を実行してください：

```bash
ollama serve
```

「port is already in use」エラーが出た場合は Ollama はすでに起動しています。そのまま補正を再試行してください。

---

## 制限事項

- **単音のみ対応** — 和音や 2 声部以上の録音には対応していません
- **4/4 拍子固定** — 3/4、6/8 などの拍子には対応していません
- **録音最長 60 秒**
- **セッション中のみ保存** — ページを閉じるとデータは消えます
